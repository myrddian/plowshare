# Working in an SDK

For SDK operations, DTOs, transport or credentials, read
[transport and SDKs](../.agents/guides/transport-sdks.md).
For permission, scope or identity changes also read [AUTH](../.agents/guides/auth.md).

Use the root language standards and the changed SDK's README for its actual
toolchain. Generated catalogs are outputs of their owning generators, not an
independent place to implement a protocol change.
