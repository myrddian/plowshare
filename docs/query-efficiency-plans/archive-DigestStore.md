# DigestStore

Status: Proposed. Source baseline: `fc36351f239b62984363ababaa1de1139402aafb`.

[DigestStore](../../plowshare-server/src/main/java/io/aeyer/plowshare/server/archive/DigestStore.java#L56) captures uncovered turns; reads roots, children, stale nodes, source spans and provenance; recursively resolves source ownership; groups nodes under ordered locks; and refreshes expected revisions. Digester/Navigator/Learner consume it. `covered(conversation)` resolves a home then calls `captureUnfolded(home)`, scanning that entire home's conversations. Repeated retention checks can therefore repeat a home-wide scan. Capture itself nests conversation and turn loops with per-turn aggregation, project lookup and two inserts: confirmed query amplification, without a latency measurement.

First resolve the home ID once; offer a conversation-bounded capture path and reuse home capture results within a sweep. Replace per-turn reads/inserts with bounded set-based candidate aggregation and inserts, preserving source order, stable leaf identity, idempotency and transaction atomicity. Group can select all ordered member rows `FOR UPDATE` in one bounded query rather than lock-then-get per member; validate every supplied revision/stale flag. Use `INSERT ... RETURNING` for the new Node. Refresh must retain its locked revision comparison. A cohesive stored capture/group function is a candidate if it actually removes round trips. [V29](../../plowshare-server/src/main/resources/db/migration/V29__memory_digests.sql#L2) already defines home/depth, edge/span/provenance keys and trigger-driven ancestor dirtying; measure range/span plans before adding indexes.

Track immutable Node DTOs by database/home/node/projection and durable content version. Existing `revision` increments on dirtying, but refresh updates summary/stale state without explicitly incrementing it here: verify current triggers and define a version covering every cached field before admission. Cache spans/provenance separately; roots and stale/children lists depend on collection membership, new parents, ancestor dirtying and source privacy. Every memory/entry/fold/provenance writer and digest trigger must invalidate after commit, not just direct DigestStore methods. Safety checks remain current; cached summaries cannot outlive revoked source visibility. Reconnect bypasses uncertain digest generations. Use the shared bounded LRU and bounded dependency fan-out.

Deliver bounded capture and batch locking first, then indexes/routines, then tracking. Mock one home resolution and bounded queries per batch, ensuring no home scan per `covered` call. Focused PostgreSQL tests are warranted for changed set-based inserts, grouping races, dirty-ancestor triggers, privacy, rollback and invalidation. No source text or operational dumps belong in evidence.
