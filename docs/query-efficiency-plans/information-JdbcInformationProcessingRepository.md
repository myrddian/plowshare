# JdbcInformationProcessingRepository

Status: Proposed; no implementation. Baseline: `fc36351f239b62984363ababaa1de1139402aafb`.

[Source](../../plowshare-server/src/main/java/io/aeyer/plowshare/server/information/JdbcInformationProcessingRepository.java#L63) owns `InformationLifecycle` queue admission, stage leases/checkpoints, source/metadata reads, extraction/policy publication, allowance claims and embedding preparation evidence. Sweeps select up to 100 rows with `FOR UPDATE SKIP LOCKED`; candidate picks one stage with predecessor, availability, SYSTEM authority and explicit-processing checks. Lease renew/require recheck token/generation/live authority. Reads include full revision, project name, budget source and grouping input; writes update stage state, extraction, tags/groups and inference bindings.

**Confirmed bounded-loop work:** sweep methods issue an update per selected candidate. Convert to a typed set-based update/returning selection preserving the locked candidate set. Sweep authorization is already deduplicated by `Authority` within a page; retain that useful reuse. Candidate retries exclude denied authority pairs; measure pages scanned and SQL-function calls rather than assuming an index solves it. `requireEmbeddingTargets` validates chunk ownership per target; batch this bounded set and compare the returned IDs. Carry project/resource/source snapshot fields in leases/read DTOs where safe, avoiding repeated name/resource reads. Do not remove renew/require fences across provider IO.

[V83](../../plowshare-server/src/main/resources/db/migration/V83__information_lifecycle.sql#L49) supplies stage identity and pending-state/lease index; [V102](../../plowshare-server/src/main/resources/db/migration/V102__information_tag_sweep.sql#L3) supplies tag candidates, while [V164](../../plowshare-server/src/main/resources/db/migration/V164__document_preparation_embedding_claims.sql#L23) indexes pending preparation. Evaluate the OR pending/expired-running query and repeated acquisition anti-join with representative plans; a partial `(revision_id)` acquisition index for non-succeeded tickets is a candidate. A bounded claim/checkpoint routine may reduce round trips, retaining stage ordering and typed lease results.

Shared caching is limited to immutable source/extracted-content DTOs keyed by database, revision, content/text hash, projection and source version; grouping/status DTOs need a distinct mutation version. Never cache queue eligibility, budgets, authorization, leases or claims. Extraction/tags/groups/stage/allowance/inference writes, catalogue rebuild/cancel/deletion, document/embedding publication and external writers invalidate status/facet/coverage memberships after commit. Use proposed tracked DTO/LRU byte bounds and current authority fences; notifications wake pending discovery, with lease-expiry timers and durable reconciliation retained. Publishing cached state before commit is forbidden.

Mock budgets should assert batch updates/target validation and no redundant project lookups per checkpoint. Later focused PostgreSQL tests cover skip-locked concurrency, expiry, explicit-only processing, claim spending, publication rollback and notification recovery. Measure worker query load separately from client dispatch delay.
