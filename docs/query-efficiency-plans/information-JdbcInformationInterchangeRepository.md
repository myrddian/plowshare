# JdbcInformationInterchangeRepository

Status: Proposed; no implementation. Baseline: `fc36351f239b62984363ababaa1de1139402aafb`.

[Source](../../plowshare-server/src/main/java/io/aeyer/plowshare/server/information/JdbcInformationInterchangeRepository.java#L22) supports `PortableInformation`. `dependencies` unions explicit inputs with pinned/current reference obligations, resolving navigation head. `relationships` bounds selection to 1–16 revisions, checks current source and neighbour disclosure before ordering/limiting links. `lockDestination` serializes namespace/name admission. `retain` writes origin and up to 17 dependency edges; `origin` reads only non-redacted provenance.

Reuse the exported bundle's already-loaded typed metadata and dependencies instead of resolving them again per serialization stage. Batch dependency discovery for the bounded bundle; compute each target navigation head once in a CTE instead of repeating it in projection/filter. Batch `retain` edge insertion via a typed array/set operation while preserving distinct/self-reference validation. [V148](../../plowshare-server/src/main/resources/db/migration/V148__information_interchange_origins.sql#L2) protects origin identity and redaction; [V147](../../plowshare-server/src/main/resources/db/migration/V147__document_navigation_policy.sql#L22) indexes graph endpoints. Measure reverse obligation selection before a new target index. A bounded table-returning export-dependency routine is an option, not an authority bypass.

Track origin DTOs by database/revision and origin version/redaction state. Relationship/dependency cache keys also need principal, full selection/read boundary, exact pinned revisions, head versions and graph/policy generations. Immutable historical bytes do not authorize current relationships. Retain/import, navigation create/remove/policy, head admission, deletion/redaction and external writers invalidate both members and query-set dependencies after commit. Keep destination locks and write admission authoritative. Use the proposed tracked immutable DTO cache with bounded expected O(1) LRU and oversized bundle bypass; notifications require durable reconnect recovery.

Mock tests should assert one dependency resolution per bundle and constant edge insertion round trips. Focused future PostgreSQL tests cover pinned versus current heads, current relationship disclosure, redaction, atomic rollback and notification recovery. Preserve the existing import receipt/no-replay behavior when optimizing dispatch.
