# Bounded SYSTEM purpose specification

Recorded before slice 08 enforcement, 18 October 2026.

SYSTEM uses its existing intrinsic root-policy grant. No task receives a new
SYSTEM role/grant, no user prompt is retried as SYSTEM, and ordinary deployment
bots keep their ordinary executor. Trusted service constructors receive the
SYSTEM operation interface explicitly. Deployment/bundle definition suppliers
remain authoritative; project definitions and user rules cannot replace workers.

| Existing purpose | Trigger / binding | Budget | Output / disclosure |
| --- | --- | --- | --- |
| Information preparation, tagging and grouping | Existing authorized submission; exact resource/revision/generation/stage lease and retained inputs | Captured revision allowance / atomic spend | Fenced writer and existing checkpoints; original private log remains subject to current access. |
| Conversation compaction and skill summary | Existing fold/handoff boundary; exact conversation and materialized span | Separate SYSTEM service-operation allowance; unlimited by default, disabled/limited only by service policy (corrected 19 October 2026) | Existing fold/generation write; no additional resource acquisition or tools. Source conversation usage attribution does not debit its allowance. |
| Scribe, Learner and memory digest/navigation | Existing write, learning window or memory operation; bounded materialized candidates/window/evidence | Existing named worker configuration or supplied digest allowance | Existing bounded verdict/checkpoint writers and audience rules. |
| Stuck advisor, call validator and command judge | Existing consult; materialized brief/commands/reply only | Existing worker model-call configuration | Verdict/advice only; no tools, delegation, arbitrary reads or direct effects. |
| Schedule reading | Existing authorized proposal request; materialized text and eligible choices | Existing reader definition allowance | Proposal only; firing requires its own account admission. |
| Embedding query/write/repair | Existing batch and own resource fences | No configured operation-call source currently exists | Refused by slice 07 until that gap is resolved; tokenizer limits/timeouts do not supply spending authority. |

The SYSTEM envelope retains purpose, immutable scope, exact root supporting grant,
worker/model identity and a digest of its fixed binding. Before dispatch and
results, current root authority and operation validity must still hold. Worker
requests are model-only. The envelope cannot acquire tools, replace its model or
change home. Each actual call retains its own allowance claim and original
accounting attempt. Unclassified/unsupported recovery remains refused.

Processing continuation tests remove creator membership, credential validity and
Application grants while retaining a valid document/operation. Processing must
continue under SYSTEM. Withdrawal/deletion, generation or lease mismatch,
unavailable retained inputs, invalid configured worker or exhausted allowance
must still stop effects. No creator permission is borrowed for processing; creator
and recipient disclosure are checked separately by existing read gates.

This slice does not invent a missing deployment/search budget source, internal
worker purpose, tool capability or public API. Operations lacking those contracts
remain explicit activation gaps, rather than falling back to owner authority.
