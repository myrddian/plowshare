# Working on architectural decisions

For a decision change, read only the matching subsystem guide from the
[wiki index](../../.agents/README.md). For authority decisions start with
[AUTH](../../.agents/guides/auth.md), not an older proposal.

Preserve historical decisions and their rationale. Mark superseded or amended
sections with a precise current-contract link; do not declare an entire ADR
obsolete when other sections remain applicable. Distinguish accepted policy,
implemented behavior, proposals and historical rollout evidence. If current
code and an accepted contract disagree, state the gap instead of silently
rewriting policy to match the implementation.
