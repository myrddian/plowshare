# Working in an integration

Read [integrations](../.agents/guides/integrations.md), then the changed adapter's
README and source. Use [AUTH](../.agents/guides/auth.md) only for authority changes;
use [deployment](../.agents/guides/deployment-operations.md) for live operations.

An integration consumes the public SDK. A missing public capability is a gap to
report; it does not authorize modifying core runtime, SQL or shared contracts.
