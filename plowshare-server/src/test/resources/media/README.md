# Still-image test vectors

These small deterministic images were generated locally with Pillow/libwebp from
solid-color pixel arrays. Files are base64 text so source/containment scans can
read every fixture; tests decode them into the original encoded WebP bytes.
No external images or private content are included.

- `still-lossy`: RGB 3x2, color (220,30,50), default WebP encoding.
- `still-lossless`: the same RGB pixels, lossless WebP encoding.
- `still-alpha`: RGBA 3x2, color (10,180,70,100), default WebP encoding; raw alpha.
- `still-compressed-alpha`: the same RGBA color at 3x20; compressed alpha.
- `animated`: RGBA 3x2, two frames (10,180,70,100) and (180,10,70,100),
  duration 100ms, loop 0. This is an admission refusal fixture.

JPEG baseline and progressive vectors are generated by Java ImageIO in tests.
