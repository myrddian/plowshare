---
name: personal-process-inbox
description: Process selected Personal Inbox captures into source-backed summaries, linked knowledge and relevant plans. Use when the user requests ingestion, distillation or filing of captured material.
mode: DIRECT
---
Resolve the authorized Personal root and read its schema, preferences and knowledge
index. Work on the requested captures. For an unspecified batch, select at most
five unprocessed captures, state the scope and report what remains.

Inspect existing source records by capture identity before writing. Resume their
unfinished steps rather than duplicating notes. Read original material through
granted file or information tools. For URL acquisition, check actual extraction
readiness; an accepted ticket or saved link is not readable evidence. Keep pending
or unavailable sources visibly unprocessed and explain their status.

For readable sources, identify the essence and how it serves an active goal,
ongoing responsibility or reusable topic. Prefer updating useful existing pages
over generating a taxonomy. Preserve source references, originals and user text.
Label synthesis and unresolved contradictions. Link relevant plans without
inventing commitments or starting work in a runnable Project.

Use skill_read for references/source.md and references/knowledge.md as needed.
Update the source record with completed and unfinished steps. Write derived pages,
check their links, update the index and append one meaningful ingest log entry.
Mark processed only after verification. On interruption leave truthful partial
status so a later invocation can continue. Report results, gaps and remaining captures.
