Resolve authorized Personal access and read the schema and index. Inspect requested
pages. If no scope was supplied, start with the index and up to ten recently changed
pages, state that limit and report remaining coverage rather than claiming a full audit.

Check links and source records, duplicate identities, unsupported claims, possible
staleness, contradictions and useful missing connections. Distinguish a genuinely
broken reference from an inaccessible source. Do not claim semantic contradictions
were resolved by a link check or that an orphan page must be deleted.

Repair mechanical problems covered by the request after reading current contents.
Preserve user commentary and conflicting source evidence. Propose substantive merges
or reinterpretations when their meaning is uncertain. Do not delete originals or
launch new research merely to fill a gap.

Use skill_read for references/report.md if helpful. Verify edits and update affected
index/source records and the meaningful change log. Return actual repairs, unresolved
findings and coverage. Leave partial work resumable rather than marking it complete.
