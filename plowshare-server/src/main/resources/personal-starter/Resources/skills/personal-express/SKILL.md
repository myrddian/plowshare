---
name: personal-express
description: Turn Personal knowledge into a requested brief, draft, decision aid or other useful deliverable in Out. Use when the user wants to create something from accumulated sources and ideas.
mode: DIRECT
---
Resolve authorized Personal access and identify the requested result, audience and
format. Read relevant knowledge, plans and source evidence. Ask about the intended
use only if it changes the artifact materially; otherwise use the task's context.

Produce the smallest useful complete deliverable. Preserve source references and
label assumptions or original synthesis. Use granted artifact tools for supported
formats; otherwise provide an honest supported format rather than inventing a file.
Use skill_read for references/deliverable.md if a Markdown structure helps.

Save the requested deliverable in Out without replacing unrelated work. Verify its
content and links. Return the artifact and a brief account of what it supports.
Drafting does not send, publish or submit it. File reusable synthesis into knowledge
only when requested or covered by the user's explicit saving preference.
