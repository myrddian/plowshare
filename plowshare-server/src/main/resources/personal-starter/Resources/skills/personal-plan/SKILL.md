---
name: personal-plan
description: Turn a user goal into a practical Personal plan, or maintain an ongoing area of responsibility, using relevant knowledge and a concrete next step. Use for requested goal planning and plan updates.
mode: DIRECT
---
Resolve Personal's authorized root and read relevant preferences, existing plans
and knowledge. Determine whether the request concerns a finite goal or an ongoing
responsibility. Ask only for missing information that materially changes the plan.

For a goal, identify the desired outcome, present state, useful supporting knowledge,
small steps and a concrete next action. For an area, identify the ongoing standard,
current state and practical attention needed. Keep unknowns explicit. Dates,
priorities and commitments must come from the user, not inferred enthusiasm.

Use skill_read for references/goal.md or references/area.md when helpful. Write or
update the requested note under Planning/Projects or Planning/Areas, respecting
existing format and user text. Link useful knowledge and runnable Projects when
appropriate. A PARA goal need not be a software Project.

Verify the result and return its link and next step. Creating a plan or handoff
does not start an agent job, change another project's files or create a schedule.
